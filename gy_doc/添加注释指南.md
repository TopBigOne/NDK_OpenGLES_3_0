### 4. OpenGL API 调用注释

```cpp
// ==================== 创建 FBO ====================
glGenFramebuffers(1, &m_FboId);             // 生成帧缓冲对象
glBindFramebuffer(GL_FRAMEBUFFER, m_FboId); // 绑定帧缓冲

// ==================== 创建颜色附件纹理 ====================
glGenTextures(1, &m_FboTextureId);          // 生成纹理对象
glBindTexture(GL_TEXTURE_2D, m_FboTextureId);  // 绑定纹理
glTexImage2D(
    GL_TEXTURE_2D,    // 纹理类型：2D 纹理
    0,                // Mipmap 层级：0（基础层）
    GL_RGBA,          // 内部格式：RGBA
    width,            // 纹理宽度
    height,           // 纹理高度
    0,                // 边框宽度（必须为0）
    GL_RGBA,          // 像素数据格式
    GL_UNSIGNED_BYTE, // 像素数据类型
    nullptr           // 像素数据指针（先不上传数据）
);
```

## 各类示例的注释重点

### 基础渲染类

#### Triangle Sample (三角形)
- 重点：渲染管线流程、顶点着色器、片段着色器
- 关键 API：glVertexAttribPointer, glDrawArrays

#### Texture Map (纹理映射)
- 重点：纹理创建、纹理坐标、采样器
- 关键 API：glTexImage2D, glTexParameteri

#### VAO Sample (顶点数组对象)
- 重点：VAO/VBO/EBO 的作用和区别
- 关键 API：glGenVertexArrays, glGenBuffers, glDrawElements

### 坐标变换类

#### Coord System (坐标系统)
- 重点：MVP 矩阵变换、GLM 库使用
- 关键概念：模型矩阵、观察矩阵、投影矩阵

### 光照类

#### Basic Lighting (基础光照)
- 重点：冯氏光照模型（环境光、漫反射、镜面反射）
- 关键概念：法线、光源位置、观察位置

#### Multi Lights (多光源)
- 重点：多光源叠加、光照衰减
- 关键概念：点光源、定向光、聚光灯

### 离屏渲染类

#### FBO Sample (帧缓冲对象)
- 重点：FBO 创建、颜色/深度附件、两遍渲染
- 关键 API：glGenFramebuffers, glFramebufferTexture2D

#### MRT (多重渲染目标)
- 重点：同时输出到多个颜色附件
- 关键 API：glDrawBuffers

### YUV 渲染类

#### NV21 Texture Map
- 重点：YUV 色彩空间、双纹理采样、YUV2RGB 转换矩阵
- 关键概念：Y 平面、UV 平面、BT.601 标准

#### RGB to NV21
- 重点：RGB2YUV 转换矩阵、MRT 应用
- 应用场景：视频编码、格式转换

### 高级特性类

#### Instancing (实例化渲染)
- 重点：实例化数组、glVertexAttribDivisor
- 性能优势：减少 draw call

#### PBO (像素缓冲对象)
- 重点：异步像素传输、乒乓缓冲
- 性能优势：避免 GPU 阻塞

#### Compute Shader (计算着色器)
- 重点：工作组、局部大小、通用 GPU 计算
- 应用场景：图像处理、粒子模拟

### 特效类

#### Beating Heart (心跳特效)
- 重点：Shader 数学函数、时间动画
- 关键函数：atan, sin, exp, smoothstep

#### Big Eyes (大眼特效)
- 重点：网格变形、局部凸变形算法
- 应用场景：美颜相机

#### Particles (粒子系统)
- 重点：粒子生命周期、混合模式、排序
- 应用场景：烟雾、火焰、喷泉

### 3D 渲染类

#### Model 3D (3D 模型加载)
- 重点：Assimp 库使用、网格数据提取
- 关键概念：Mesh、Material、Texture

#### SkyBox (天空盒)
- 重点：立方体贴图、环境映射
- 关键 API：GL_TEXTURE_CUBE_MAP

## 注释质量要求

### ✅ 良好的注释应该包含

1. **WHY（为什么）**: 解释为什么这样做
   ```cpp
   // 使用 VAO 可以避免每帧重复设置顶点属性，提高性能
   glBindVertexArray(m_VaoId);
   ```

2. **WHAT（是什么）**: 说明这段代码做了什么
   ```cpp
   // 创建帧缓冲对象，用于离屏渲染
   glGenFramebuffers(1, &m_FboId);
   ```

3. **HOW（怎么做）**: 解释技术原理
   ```cpp
   // YUV 到 RGB 转换使用 BT.601 标准矩阵
   // R = Y + 1.403 * (V - 0.5)
   // G = Y - 0.344 * (U - 0.5) - 0.714 * (V - 0.5)
   // B = Y + 1.770 * (U - 0.5)
   ```

4. **参数说明**: 详细解释每个参数的含义
   ```cpp
   glVertexAttribPointer (
       0,                // location: 顶点属性索引
       3,                // size: 每个顶点有 3 个分量（x, y, z）
       GL_FLOAT,         // type: 数据类型为浮点
       GL_FALSE,         // normalized: 不需要归一化
       0,                // stride: 步长为 0（紧密排列）
       vVertices         // pointer: 顶点数据指针
   );
   ```

### ❌ 应该避免的注释

1. **重复代码内容**（无用注释）
   ```cpp
   // 错误示例
   int width = 1920;  // 设置宽度为 1920

   // 正确示例
   int width = 1920;  // 设置为 Full HD 宽度
   ```

2. **过时的注释**
   ```cpp
   // 错误示例：注释与代码不一致
   // 设置颜色为红色
   fragColor = vec4(0.0, 1.0, 0.0, 1.0);  // 实际是绿色
   ```

3. **显而易见的注释**
   ```cpp
   // 错误示例
   i++;  // i 加 1

   // 正确示例（如果必要）
   frameCount++;  // 记录已渲染的帧数，用于性能统计
   ```
