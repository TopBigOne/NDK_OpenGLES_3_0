## 1. 项目概述

### 1.1 项目简介

NDK_OpenGLES_3_0 是一个系统性的 OpenGL ES 3.0 学习教程项目，由公众号"字节流动"创建和维护。该项目通过 61 个实际示例，涵盖了从基础渲染到高级特效的完整 OpenGL ES 技术栈。

### 1.2 核心特点

- **跨平台设计**: 核心渲染代码使用 C++ 实现，支持 Android、iOS、Windows、Linux 平台
- **NDK 开发**: 使用 Android NDK 进行原生开发，充分发挥 GPU 性能
- **完整示例**: 包含 61 个可交互示例，131+ 个 C++ 示例实现类
- **生产级代码**: 代码结构清晰，设计模式完善，可直接应用于生产环境

### 2.2 设计模式

#### 2.2.1 单例模式 (Singleton Pattern)

**MyGLRenderContext** 采用单例模式管理全局渲染上下文：

```cpp
class MyGLRenderContext {
public:
    static MyGLRenderContext* GetInstance();
    static void DestroyInstance();

private:
    static MyGLRenderContext *m_pContext;
    MyGLRenderContext();  // 私有构造函数
    ~MyGLRenderContext();
};
```

**优点**:
- 保证全局唯一的渲染上下文
- 方便从任意位置访问渲染器
- 统一管理 OpenGL 状态

#### 2.2.2 策略模式 (Strategy Pattern)

**GLSampleBase** 作为抽象基类，定义了渲染的标准接口：

```cpp
class GLSampleBase {
public:
    virtual void LoadImage(NativeImage *pImage) {};
    virtual void Init() = 0;         // 纯虚函数
    virtual void Draw(int screenW, int screenH) = 0;
    virtual void Destroy() = 0;

protected:
    GLuint m_ProgramObj;
    int m_SurfaceWidth;
    int m_SurfaceHeight;
};
```

每个具体示例类继承 `GLSampleBase` 并实现自己的渲染策略：

```cpp
class TriangleSample : public GLSampleBase {
public:
    virtual void Init() override;
    virtual void Draw(int screenW, int screenH) override;
    virtual void Destroy() override;
};
```

**优点**:
- 统一的接口，便于切换不同示例
- 易于扩展新示例
- 代码复用性高

#### 2.2.3 工厂模式 (Factory Pattern)

**MyGLRenderContext** 根据示例类型创建对应的示例对象：

```cpp
void MyGLRenderContext::SetParamsInt(int paramType, int value0, int value1) {
    if (paramType == SAMPLE_TYPE) {
        switch (value0) {
            case SAMPLE_TYPE_KEY_TRIANGLE:
                m_pCurSample = new TriangleSample();
                break;
            case SAMPLE_TYPE_KEY_TEXTURE_MAP:
                m_pCurSample = new TextureMapSample();
                break;
            // ... 其他 59 个示例
        }
    }
}
```

**优点**:
- 集中管理对象创建逻辑
- 解耦对象创建和使用
- 便于添加新的示例类型

## 3. 核心模块分析

### 3.1 JNI 桥接层

#### 3.1.1 JNI 接口设计

项目使用**动态注册**方式注册 JNI 方法，提高性能并避免命名冲突：

```cpp
// JNI 方法表
static JNINativeMethod g_RenderMethods[] = {
    {"native_Init",                 "()V",       (void *)(native_Init)},
    {"native_SetImageData",         "(III[B)V",  (void *)(native_SetImageData)},
    {"native_OnSurfaceCreated",     "()V",       (void *)(native_OnSurfaceCreated)},
    {"native_OnSurfaceChanged",     "(II)V",     (void *)(native_OnSurfaceChanged)},
    {"native_OnDrawFrame",          "()V",       (void *)(native_OnDrawFrame)},
    // ... 其他方法
};

// JNI_OnLoad 时动态注册
extern "C" jint JNI_OnLoad(JavaVM *jvm, void *p) {
    JNIEnv *env = NULL;
    jvm->GetEnv((void **)(&env), JNI_VERSION_1_6);

    RegisterNativeMethods(env, NATIVE_RENDER_CLASS_NAME,
                         g_RenderMethods,
                         sizeof(g_RenderMethods) / sizeof(g_RenderMethods[0]));

    return JNI_VERSION_1_6;
}
```

#### 3.1.2 数据传输优化

**图像数据传输**采用了内存拷贝优化策略：

```cpp
JNIEXPORT void JNICALL native_SetImageData(
    JNIEnv *env, jobject instance,
    jint format, jint width, jint height, jbyteArray imageData) {

    int len = env->GetArrayLength(imageData);
    uint8_t* buf = new uint8_t[len];

    // 从 Java 字节数组拷贝到 Native 缓冲区
    env->GetByteArrayRegion(imageData, 0, len, reinterpret_cast<jbyte*>(buf));

    // 传递给渲染上下文
    MyGLRenderContext::GetInstance()->SetImageData(format, width, height, buf);

    // 释放本地缓冲区
    delete[] buf;
    env->DeleteLocalRef(imageData);
}
```

**优点**:
- 及时释放 JNI 引用，避免内存泄漏
- 使用局部缓冲区，避免长时间持有 Java 数组

### 3.2 渲染管理层

#### 3.2.1 MyGLRenderContext 类

这是整个渲染系统的核心管理类，负责：

1. **示例生命周期管理**
```cpp
class MyGLRenderContext {
private:
    GLSampleBase *m_pBeforeSample;  // 前一个示例
    GLSampleBase *m_pCurSample;     // 当前示例

public:
    void OnSurfaceCreated() {
        if (m_pBeforeSample) {
            m_pBeforeSample->Destroy();  // 销毁旧示例
            delete m_pBeforeSample;
            m_pBeforeSample = nullptr;
        }
        if (m_pCurSample) {
            m_pCurSample->Init();  // 初始化新示例
        }
    }
};
```

2. **OpenGL 渲染循环**
```cpp
void MyGLRenderContext::OnDrawFrame() {
    if (m_pCurSample) {
        m_pCurSample->Draw(m_ScreenW, m_ScreenH);
    }
}
```

3. **数据传递**
```cpp
void MyGLRenderContext::SetImageData(int format, int width, int height, uint8_t *pData) {
    NativeImage nativeImage;
    nativeImage.format = format;
    nativeImage.width = width;
    nativeImage.height = height;
    nativeImage.ppPlane[0] = pData;

    if (m_pCurSample) {
        m_pCurSample->LoadImage(&nativeImage);
    }
}
```

#### 3.3.3 典型示例分析: BeatingHeartSample

**心跳特效** 是一个展示 Shader 编程和数学运算的优秀示例。

**核心技术**:
1. **时间动画**: 使用 uniform 变量传递时间，实现动态效果
2. **数学函数**: 使用 atan、sin、exp 等函数构造心形
3. **平滑插值**: smoothstep 实现边缘抗锯齿

**片段着色器核心代码**:
```glsl
// 心形数学公式
float a = atan(p.x, p.y) / 3.141592653;
float r = length(p);
float h = abs(a);
float d = (13.0*h - 22.0*h*h + 10.0*h*h*h) / (6.0-5.0*h);

// 动画效果 (基于时间 u_time)
float tt = u_time;
float ss = pow(tt, 0.2) * 0.5 + 0.5;
ss = 1.0 + ss*0.5*sin(tt*6.2831*3.0 + p.y*0.5)*exp(-tt*4.0);

// 颜色混合
vec3 col = mix(bcol, hcol, smoothstep(-0.06, 0.06, d-r));
```

**版本**: Header-only library
**路径**: `app/src/main/cpp/glm/`

- 向量运算 (vec2, vec3, vec4)

**典型使用**:
```cpp
#include <glm.hpp>

// 创建变换矩阵
glm::mat4 model = glm::mat4(1.0f);
model = glm::translate(model, glm::vec3(0.0f, 0.0f, -3.0f));
model = glm::rotate(model, glm::radians(45.0f), glm::vec3(0.0f, 1.0f, 0.0f));

glm::mat4 view = glm::lookAt(
    glm::vec3(0.0f, 0.0f, 3.0f),  // 相机位置
    glm::vec3(0.0f, 0.0f, 0.0f),  // 目标点
    glm::vec3(0.0f, 1.0f, 0.0f)   // 上向量
);

glm::mat4 projection = glm::perspective(
    glm::radians(45.0f),          // FOV
    aspect,                        // 宽高比
    0.1f, 100.0f                  // 近/远平面
);

glm::mat4 mvp = projection * view * model;
```

## 5. 渲染管线分析

### 5.1 标准渲染流程

以 **TriangleSample** (绘制三角形) 为例：

#### 5.1.1 初始化阶段 (Init)

```cpp
void TriangleSample::Init() {
    // 1. 定义顶点数据
    GLfloat vertices[] = {
        0.0f,  0.5f, 0.0f,  // 顶点 0
       -0.5f, -0.5f, 0.0f,  // 顶点 1
        0.5f, -0.5f, 0.0f   // 顶点 2
    };

    // 2. 编译着色器
    char vShaderStr[] =
        "#version 300 es\n"
        "layout(location = 0) in vec4 vPosition;\n"
        "void main() {\n"
        "    gl_Position = vPosition;\n"
        "}\n";

    char fShaderStr[] =
        "#version 300 es\n"
        "precision mediump float;\n"
        "out vec4 fragColor;\n"
        "void main() {\n"
        "    fragColor = vec4(1.0, 0.0, 0.0, 1.0);\n"
        "}\n";

    m_ProgramObj = GLUtils::CreateProgram(vShaderStr, fShaderStr);

    // 3. 创建 VBO
    glGenBuffers(1, &m_VboId);
    glBindBuffer(GL_ARRAY_BUFFER, m_VboId);
    glBufferData(GL_ARRAY_BUFFER, sizeof(vertices), vertices, GL_STATIC_DRAW);

    // 4. 创建 VAO
    glGenVertexArrays(1, &m_VaoId);
    glBindVertexArray(m_VaoId);
    glBindBuffer(GL_ARRAY_BUFFER, m_VboId);
```

### 5.2 高级渲染管线

以 **FBOSample** (离屏渲染) 为例，展示更复杂的渲染流程：

#### 5.2.1 FBO 创建和配置

```cpp
void FBOSample::Init() {
    // 1. 创建 FBO
    glGenFramebuffers(1, &m_FboId);
    glBindFramebuffer(GL_FRAMEBUFFER, m_FboId);

    // 2. 创建颜色附件纹理
    glGenTextures(1, &m_FboTextureId);
    glBindTexture(GL_TEXTURE_2D, m_FboTextureId);
    glTexImage2D(GL_TEXTURE_2D, 0, GL_RGBA,
                 m_RenderImage.width, m_RenderImage.height,
                 0, GL_RGBA, GL_UNSIGNED_BYTE, nullptr);
    glTexParameterf(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_CLAMP_TO_EDGE);
    glTexParameterf(GL_TEXTURE_2D, GL_TEXTURE_WRAP_T, GL_CLAMP_TO_EDGE);
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR);
    glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);

    // 3. 附加纹理到 FBO
    glFramebufferTexture2D(GL_FRAMEBUFFER, GL_COLOR_ATTACHMENT0,
                          GL_TEXTURE_2D, m_FboTextureId, 0);

    // 4. 检查 FBO 完整性
    if (glCheckFramebufferStatus(GL_FRAMEBUFFER) != GL_FRAMEBUFFER_COMPLETE) {
        LOGCATE("FBOSample::Init FBO is incomplete");
    }

    glBindFramebuffer(GL_FRAMEBUFFER, GL_NONE);
}
```

```cpp
void FBOSample::Draw(int screenW, int screenH) {

    glUseProgram(m_ProgramObj);
    glBindVertexArray(m_VaoIds[1]);
```

```glsl
        1.403,    -0.714,   0.0
```

## 6. 性能优化策略

### 6.1 渲染优化

#### 6.1.1 VAO/VBO 使用

**优点**:
- 减少 CPU 到 GPU 的数据传输
- 避免每帧重复设置顶点属性
- 提高渲染性能

**实践**:
```cpp
// 初始化时创建 VAO
glGenVertexArrays(1, &m_VaoId);
glBindVertexArray(m_VaoId);
// ... 配置顶点属性
glBindVertexArray(GL_NONE);

// 渲染时只需绑定 VAO
glBindVertexArray(m_VaoId);
glDrawArrays(GL_TRIANGLES, 0, vertexCount);
```

#### 6.1.2 实例化渲染 (Instancing)

用于渲染大量相同几何体 (如粒子、草丛、树木)：

```cpp
// 顶点着色器
#version 300 es
layout(location = 0) in vec3 a_position;
layout(location = 1) in vec2 a_offset;  // 实例化属性

void main() {
    gl_Position = vec4(a_position + vec3(a_offset, 0.0), 1.0);
}

// 配置实例化属性
glEnableVertexAttribArray(1);
glVertexAttribPointer(1, 2, GL_FLOAT, GL_FALSE, 2 * sizeof(float), (void*)0);
glVertexAttribDivisor(1, 1);  // 每个实例更新一次

// 实例化绘制
glDrawArraysInstanced(GL_TRIANGLES, 0, 6, 100);  // 绘制 100 个实例
```

#### 6.1.3 PBO 异步读取

像素缓冲对象 (PBO) 用于异步读取像素数据，避免阻塞 GPU：

```cpp
// 创建 PBO
GLuint pboIds[2];
glGenBuffers(2, pboIds);
glBindBuffer(GL_PIXEL_PACK_BUFFER, pboIds[0]);
glBufferData(GL_PIXEL_PACK_BUFFER, dataSize, 0, GL_STREAM_READ);
glBindBuffer(GL_PIXEL_PACK_BUFFER, pboIds[1]);
glBufferData(GL_PIXEL_PACK_BUFFER, dataSize, 0, GL_STREAM_READ);

// 异步读取 (乒乓缓冲)
int index = frameIndex % 2;
int nextIndex = (frameIndex + 1) % 2;

// 启动异步读取到 PBO
glBindBuffer(GL_PIXEL_PACK_BUFFER, pboIds[index]);
glReadPixels(0, 0, width, height, GL_RGBA, GL_UNSIGNED_BYTE, 0);

// 从另一个 PBO 读取上一帧数据
glBindBuffer(GL_PIXEL_PACK_BUFFER, pboIds[nextIndex]);
GLubyte* ptr = (GLubyte*)glMapBufferRange(GL_PIXEL_PACK_BUFFER, 0, dataSize,
                                          GL_MAP_READ_BIT);
if (ptr) {
    // 处理数据
    glUnmapBuffer(GL_PIXEL_PACK_BUFFER);
}
```

### 6.2 内存优化

#### 6.2.1 纹理压缩

使用 ETC2 或 ASTC 压缩格式减少内存占用：

```cpp
// ETC2 压缩纹理
```

### 7.1 EGL 后台渲染

项目支持在后台线程进行 OpenGL 渲染，通过 **EGLRender** 类实现：

#### 7.1.1 EGL 上下文创建

```cpp
class EGLRender {
private:
    EGLDisplay m_eglDisplay;
    EGLConfig m_eglConfig;
    EGLContext m_eglContext;
    EGLSurface m_eglSurface;

public:
    void Init() {
        // 1. 获取 EGL Display
        m_eglDisplay = eglGetDisplay(EGL_DEFAULT_DISPLAY);
        eglInitialize(m_eglDisplay, nullptr, nullptr);

        // 2. 选择配置
        EGLint attribs[] = {
            EGL_SURFACE_TYPE, EGL_PBUFFER_BIT,  // 离屏渲染
            EGL_RENDERABLE_TYPE, EGL_OPENGL_ES3_BIT,
            EGL_RED_SIZE, 8,
            EGL_GREEN_SIZE, 8,
            EGL_BLUE_SIZE, 8,
            EGL_ALPHA_SIZE, 8,
            EGL_DEPTH_SIZE, 16,
            EGL_NONE
        };
        EGLint numConfigs;
        eglChooseConfig(m_eglDisplay, attribs, &m_eglConfig, 1, &numConfigs);

        // 3. 创建 PBuffer Surface
        EGLint pbufferAttribs[] = {
            EGL_WIDTH, 1,
            EGL_HEIGHT, 1,
            EGL_NONE
        };
        m_eglSurface = eglCreatePbufferSurface(m_eglDisplay, m_eglConfig, pbufferAttribs);

        // 4. 创建 Context
        EGLint contextAttribs[] = {
            EGL_CONTEXT_CLIENT_VERSION, 3,
            EGL_NONE
        };
        m_eglContext = eglCreateContext(m_eglDisplay, m_eglConfig,
                                       EGL_NO_CONTEXT, contextAttribs);

        // 5. 激活上下文
        eglMakeCurrent(m_eglDisplay, m_eglSurface, m_eglSurface, m_eglContext);
    }
};
```

#### 7.1.2 多线程渲染

```cpp
// SharedEGLContextSample 实现共享 EGL 上下文
class SharedEGLContextSample : public GLSampleBase {
private:
    thread m_thread;
    bool m_threadExit;

    void RenderThread() {
        // 创建共享上下文
        EGLContext sharedContext = eglCreateContext(display, config,
            m_eglContext,  // 共享主上下文
            contextAttribs);
        eglMakeCurrent(display, surface, surface, sharedContext);

        // 渲染循环
        while (!m_threadExit) {
            // 在后台线程进行渲染
            glClear(GL_COLOR_BUFFER_BIT);
            // ... 渲染代码
            eglSwapBuffers(display, surface);
        }

        // 清理
        eglDestroyContext(display, sharedContext);
    }

public:
    void Init() override {
        // 启动渲染线程
        m_threadExit = false;
        m_thread = thread(&SharedEGLContextSample::RenderThread, this);
    }

    void Destroy() override {
        // 停止渲染线程
        m_threadExit = true;
        if (m_thread.joinable()) {
            m_thread.join();
        }
    }
};
```

### 7.2 线程同步

使用 **MySyncLock** (基于 pthread_mutex) 保护共享资源：

```cpp
class MySyncLock {
private:
    pthread_mutex_t m_mutex;

public:
    MySyncLock() {
        pthread_mutex_init(&m_mutex, nullptr);
    }

    ~MySyncLock() {
        pthread_mutex_destroy(&m_mutex);
    }

    void lock() {
        pthread_mutex_lock(&m_mutex);
    }

    void unlock() {
        pthread_mutex_unlock(&m_mutex);
    }
};

// 使用示例
class GLSampleBase {
protected:
    MySyncLock m_Lock;

public:
    void LoadImage(NativeImage *pImage) {
        m_Lock.lock();
        // ... 访问共享数据
        m_Lock.unlock();
    }
};
```

## 10. 最佳实践和建议

### 10.1 代码组织

1. **单一职责原则**: 每个 Sample 类只负责一个示例的渲染
2. **资源管理**: 在 Init/Destroy 中成对管理 OpenGL 资源
3. **着色器管理**: 使用常量字符串或外部文件存储着色器代码
4. **错误处理**: 关键 OpenGL 调用后检查错误

### 10.2 性能建议

1. **减少状态切换**: 批量处理相同状态的绘制调用
2. **使用 VAO**: 避免每帧重复设置顶点属性
3. **纹理复用**: 使用纹理图集 (Texture Atlas) 减少纹理切换
4. **实例化渲染**: 大量相同物体使用 glDrawArraysInstanced
5. **异步操作**: 使用 PBO 异步读取像素数据

### 10.3 跨平台移植

核心渲染代码已经实现了平台无关性，移植到 iOS/Windows/Linux 只需：

1. **保留 C++ 层**: `sample/`, `render/`, `util/` 目录完全复用
2. **替换 UI 层**: 使用各平台的窗口系统 (UIKit/GLFW/X11)
3. **替换 JNI 层**: iOS 直接调用 C++，Windows/Linux 使用 JNI 或直接调用
4. **调整构建系统**: CMake 配置适配不同平台

### 10.4 扩展新示例

### C. 常见问题

**Q1: 编译时找不到 assimp.so?**
A: 检查 `app/src/main/jniLibs/arm64-v8a/` 目录是否存在该文件。

**Q2: 运行时黑屏?**
A: 检查 Logcat 日志，通常是着色器编译失败或纹理加载问题。

**Q3: 如何添加新的 ABI 支持?**
A: 在 `build.gradle` 的 `ndk.abiFilters` 中添加，并提供对应的 .so 文件。

**Q4: 为什么使用 NDK r21 而不是最新版本?**
A: 项目兼容性考虑，r21 是稳定版本，且支持所有示例功能。
